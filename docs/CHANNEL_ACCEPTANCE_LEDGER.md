## 续跑规则（每轮必须落盘）

1. 先读取本表及 DEVELOPMENT_CHECKPOINT.md 最新章节，核验 main SHA、工作树、安装版本和最近私有回执。先挑最高优先级、当前能够实做的 G/U 项；不以新增版本号、测试数量作为业务进度。
2. 每项记录：ID、源码/提交、故障复现证据、修复、专项和全量测试、CI/合并 SHA、生产版本及官方证据、剩余缺口和下次唯一行动。没有新证据不得将 G/U 改为通过。已通过项只在变更、证据到期或新故障时复验。
3. 用既有正式入口运行只读审计：`node tools/audit-installed-state-readonly.mjs`。已授权 Owner 入口参照 RC113_LOCAL_OWNER_JOBS.md；先 inventory 或 owned-autofree-audit，精确渠道可用 host-route，只有官方确认免费且确需复验才发推理。已有确认活动不再提交；临时委托用后撤销。生产版本落后时集中安装验证，不重复要求逐版升级。
4. Runner 离线时记录阻塞，不擅自换电脑；恢复时核验原工作树和 runner 身份。继续 ID-01、ID-02、GIFT-01、LOOMY-01，不从已经通过的旧版测试重新开始。
