# rc.102 后台证据持久化及精确账号刷新

- rc.100 实机只读审计：10 个启用账号均有近期在线鉴权，7 个有效名称，另一个 Loomy 账号有脱敏手机号；8 个余额数值、1 个缺单位。CodeArts 与 ZCode 无已保存身份。rc.100 尚未存储周期额度观测字段，不能据此判定 MiMo 或豆包没有权益。今日签到及奖励回执为零，最近完整推理证明为零。
- 后台显式刷新和只读状态刷新在成功且仍绑定原启用账号时持久化公开资料；记录额度观测状态、窗口数量与是否有官方百分比，不额外保存实际百分比、原始响应或凭据。过期状态不冒充实时权益。账号列表的普通读取不会更新官方观测时间。
- 后台盘点在驱动有官方状态接口时定向查询一个账号，避免额外模型目录刷新；显式操作与同账号正在运行的只读刷新不并行。
- 审计区分名称、脱敏身份、余额数值、近期余额记录和周期额度观测；最新失败晚于先前成功时，不计为近期完整推理证明。
- 本地合成夹具验证真实代码路径，生产实机仅执行匿名只读审计。未调用生产账号推理、领取奖励或改变生产配置；仍需在正式 Owner 授权上下文中完成真实渠道验收。
