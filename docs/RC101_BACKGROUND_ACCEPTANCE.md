# rc.101 后台验收及额度状态

## 运行期验收

优先通过正式 DSH Connection Owner 认证管理接口，避免操作前台、读取进程内存、导出凭据或重启宿主。新接口注册在原 DSH 服务端口的 /api/plugins/dsh-native-router/acceptance，匿名请求拒绝，写操作受原有 Owner 认证和 Origin 检查约束，不创建额外服务或替代身份认证。

- GET：读取最近一次任务状态，初始 idle，无网络请求。
- POST：{"action":"start","requestId":"<32位小写十六进制唯一请求ID>","mode":"inventory","consent":true}。可选 channel（只处理指定渠道）。盘点原生自有、已启用账号；不进行推理或领取。
- mode=free-models：逐账号重新读取模型目录，最多一次最小输出推理，仅依据明确官方免费信息；人工免费标记不能单独作为自动验收依据，任何明确正倍率或冲突价格都拒绝。保留用户手动费用排除规则。无免费证据则跳过。
- mode=channel-activity：必须指定 channel，调用已有真实签到及免费活动执行器，返回官方回执分级汇总，不更改全局或渠道自动开关。既有防重复及活动资格校验继续生效。
- POST：{"action":"cancel","requestId":"<原ID>"}，停止后续任务，不强制中断已提交官方请求。
- 一次一个任务、最多16个自有账号，本插件运行期最多128个唯一任务 ID，重复相同请求返回原任务报告。报告不包含账号明文、凭据、余额数值或模型回复。重启后运行期任务状态不保留，签到与领取仍使用原持久化防重复记录。

## 会员额度

MiMo 七日自然恢复与会员额度不是积分钱包。新响应明确无周期或缺失数字时不继承旧百分比/恢复时间。豆包额度查询暂时失败时，已知历史金额保留原时间并标记缓存，不能变为实时官方余额；查询恢复后才恢复 available。

## 验收边界

在原绑定 Windows 工作树开发并运行真实回归和隔离 DSH 宿主验证。生产宿主未被重启，未操作前台窗口，也未导出身份材料。新接口只有升级并加载新插件后才能在正常授权会话中使用；隔离合成账号不代表真实账号在线调用、官方奖励到账或真实云端费用。生产全渠道验收仍需通过正式授权路径完成。
