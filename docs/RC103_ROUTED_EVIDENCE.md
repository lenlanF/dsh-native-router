# rc.103：正常路由证据、观测迁移与无浏览器验收

- rc.102 实机只读核查：10 个启用账号均有近期鉴权记录；8 个有可识别身份（其中 Loomy 仅脱敏身份）；8 个有余额，余额单位全部恢复。最新安装后的新进程仍使用旧鉴权周期，暂无持久化额度观测、今日签到记录或近期完整推理证据。不将未记录额度认定为零余额。
- 正常自有账号路由的完整有效回复写入对应绑定的模型证据。账户变动、取消和输出截断不算完整证明；失败切换独立记录，其他模型瞬时失败不误清除已确认的健康模型证明。普通路由证据与费用授权分开，不用于判定免费。
- 迁移旧版缓存时对缺失观测的已绑定账号执行周期内一次官方只读补齐，不因此启用自动领取。
- 新增可选命令行工具 `tools/owner-acceptance-cli.mjs`，仅接受由 Owner 通过 DSH 正式机制授权的本机登录链接，输入使用 stdin，不能放在命令行参数、聊天内容或版本库中。此工具不从浏览器、进程或凭据存储提取会话；没有新监听端口或认证旁路。
- 支持 `status`、`start --mode inventory --request-id <32位小写十六进制ID> --consent`、`start --mode free-models --request-id <ID> --consent`、`start --mode channel-activity --channel <渠道> --request-id <ID> --consent` 及 `cancel --request-id <ID>`。登录链接必须通过安全的 stdin 输入，实际执行前明确同意；重复同一 ID 由宿主拒绝重复执行。工具不自动重发请求，不输出登录链接、Cookie、原始响应或账号姓名。
- 测试环境使用真正 DSH Connection 签发的隔离登录链接和合成账号。生产环境只执行本地匿名审计和未登录接口状态检查，未发送真实推理、领取请求或改变生产配置。真实渠道到账与模型验收仍须通过生产 Owner 授权上下文执行。
