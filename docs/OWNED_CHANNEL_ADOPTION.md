# 聚合路由：原渠道账号独立接管（RC.4）

## 两种模式

- **委托复用**：使用宿主已有 DSH Provider 的模型与登录态；原插件停止后，委托路径会失效。
- **独立接管**：对兼容 DSH AccountPool 的账号，在用户逐账号确认后，将凭据复制到聚合路由独立 DSH Credentials 引用和私有持久化账号池。原插件账号、授权、路由不被修改。

## 使用步骤

1. 打开「复用管理 → 自主登录」，开启内置渠道包并保存，必要时重新加载 DSH。无需额外网关或独立服务。DSH Node.js 要求 >=22.10.0。
2. 打开「复用管理 → 本机登录态」，点击「检测可迁移账号」。只显示来源平台、账号显示名以及是否可迁移，不展示 Token、Cookie、凭据名和原始路径。
3. 按账号逐个点击「接管到本插件」并确认。插件仅在此时从原 DSH Credentials 取出兼容凭据，在相同 DSH 保管库中创建新名字的副本，写入私有 nativeRouterSourceAccountPool，原账号不变。
4. 新的自有 Provider 名称为 own_加原渠道名，独立模型链以 owned_开头。原 Provider 保留。对原有优先级模型链，只追加自有后备档位；固定模式不偷偷修改。
5. **接管副本存储完成并不等于独立推理已验证。** 内置渠道和宿主原 Provider 冲突时不会抢注册。请先在隔离、备份完毕的环境停止原 Provider、重新加载 DSH，再验证自有模型真实调用、登录续期及每日签到；全部验证前不要认定可以安全卸载旧插件。

## WorkBuddy 双区域原生账号独立接管（RC.8）

在「复用管理 → 本机登录态」检查账户时，将 MIT WorkBuddy 原插件的国内、国际 vault 分开显示。必须逐账号确认才复制原授权到本插件独立 DSH Credentials，并创建 `own_workbuddy-cn` / `own_workbuddy-global` Provider 及模型链。优先按当前账号实际模型目录填入有效模型，目录不可用时标记待核验。整个流程不删除、覆盖或退出原插件账号。

自有驱动无需原插件运行，按 CN/global 两区的 MIT 实际协议访问模型；过期会话的续期走 `X-Refresh-Token`，刷新成功写回自有凭据库；签到需先查询当天活动，再领取并核对上游今日状态。离线模拟证明原文件删除后的推理/签到以及重启后继续读取刷新令牌；真实插件停用及长期云端续期仍需隔离环境最终验收。

## Loomy 和 ZCode Start Plan 私有授权接管（RC.7）

本项目已内置的 MIT 渠道包包含 Loomy 微信扫码/短信、模型、积分，以及 ZCode 设备会话、验证码和模型协议。点击「复用管理 → 自主登录」开启渠道包并保存、重新加载 DSH，待确认挂载；在「本机登录态」逐个选择 Loomy / ZCode Start Plan 原授权并明确批准复制。新的安全凭据和账号仅保存在本插件私有渠道池中，原插件的账号/数据库不变；新增 `own_loomy` / `own_zcode` 自有模型。旧插件仍注册同名 Provider 时本插件不会抢占；应在隔离/备份环境停用旧插件、重新加载 DSH，执行真实推理和签到后再认定独立有效。**没有真实服务端确认的结果，不标记已验收。**

## 适用范围与限制

- 仅支持原 DSH 宿主已注册、具有可辨识且唯一的 AccountPool 账号与安全凭据引用、并与本插件内置适配器兼容的渠道。最多 13 种内置渠道原生适配，具备逐账号每日签到接口的为其中 9 类；真实兼容性须逐渠道验收。
- WorkBuddy 等插件可能采用私有账号管理而不是共享 AccountPool；原 Provider 已注册不代表可以直接提取其授权。可尝试独立 WorkBuddy 桌面只读授权（依赖仍有效的官方客户端会话）或通过本插件原生扫码／网页登录重新获取授权。
- 凭据过期、云端撤销、设备绑定、不同版本授权格式或刷新策略，都可能需要重新登录。原插件停用后也必须验证，不能仅凭存储成功声称在线可用。
- 插件只在管理界面账号所有者明确同意后复制；非兼容账号、无持久化存储、模糊账号选择或不安全凭据一律拒绝。原账号及原凭据永远不被自动删除、覆盖或退出。

## 安全与自动化验证

- 接管 API 处于 DSH Connection 所有者身份验证和 Origin 防护后；浏览器不接收原凭据；插件配置、GitHub 和日志不保存 Token。
- 自动测试使用虚构凭据模拟：验证接管后凭据仍由私有存储持有、原插件凭据删除后自有模型推理与签到仍可工作、拒绝未同意和不兼容账号、拒绝跨来源调用。
- 模拟测试不等于真实 DSH 桌面账号或在线云端认证通过。正式环境接管、原插件卸载与发布稳定版仍需单独验收。
